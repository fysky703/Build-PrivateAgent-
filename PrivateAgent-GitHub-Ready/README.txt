# PrivateAgent GitHub Workflows

Copy the `.github` folder into the root of the PrivateAgent repository.

Expected structure:

PrivateAgent/
├── .github/
│   └── workflows/
│       ├── agent-android.yml
│       ├── admin-android.yml
│       └── validate.yml
├── apps/
│   ├── agent/
│   └── admin/
├── firebase/
└── README.md

After pushing to GitHub, open **Actions** to see the workflows.
